# `data/` — inputs and the provenance contract

```
raw/        source material — some downloaded, some hand-curated
processed/  everything the pipeline derives
```

Only small, hand-curated files are tracked in git. Anything re-downloadable is
ignored, because a repository is a bad place to store 229 MB of regulatory CSVs.

| file | tracked | why |
|---|---|---|
| `raw/disclosure_corpus.json` | **yes** | curated input, the heart of the intent layer |
| `raw/ir_sources.json` | **yes** | hand-maintained, includes browser-resolved URLs |
| `raw/tr_cre.csv`, `tr_oth.csv`, `TR_Metadata.xlsx` | no | ~130 MB, re-fetchable |
| `raw/reports/` | no | cached bank PDFs, re-downloadable |
| `processed/*` | yes | small, and lets a reader see outputs without running anything |

Restore the ignored files with `python scripts/fetch_data.py`.

---

## `raw/disclosure_corpus.json` — the contract

This file is the one with rules, because it is the only place where free text
enters a system that produces rankings.

**Every entry is `VERIFIED_VERBATIM`.** The quote was located in the PDF it cites
by `scripts/promote_candidates.py`, which re-opens the cached source document and
matches the text. Nothing here is paraphrased, summarised, or model-generated.

```json
{
  "lei": "<20-char LEI>",
  "bank": "Example Bank AG",
  "source_document": "Annual_Report_2025.pdf",
  "source_url": "https://example.com/.../Annual_Report_2025.pdf",
  "page_no": 117,
  "quote": "<verbatim passage, copied exactly>",
  "provenance": "VERIFIED_VERBATIM",
  "verification": "Located in source PDF by scripts/promote_candidates.py"
}
```

Three rules this file enforces:

1. **A quote that cannot be located in its stated source is never written.**
   Verification is mechanical and reproducible — same document in, same answer
   out — not somebody asserting they checked.
2. **No placeholder text.** Earlier builds carried clearly-labelled sample
   language so the pipeline could be exercised before real documents were
   reachable. It has been removed. Invented sentences attached to real bank names
   are a liability in a public repository even when flagged and scored at zero.
3. **A bank absent from this file has not been read yet.** It is reported
   downstream as *intent unconfirmed*, never as silent. Absence of data is not
   evidence of absence.

`src/intent.py` fails closed: anything arriving without explicit
`VERIFIED_VERBATIM` provenance scores zero and cannot reach the ranking.

## `raw/ir_sources.json` — where to look

Investor-relations entry points per bank, plus the `lang` that selects the
keyword set — a German bank writes *notleidende Kredite*, an Italian one *crediti
deteriorati*, and neither says "NPL".

`direct_pdfs` holds report URLs resolved by loading the IR page in a real
browser. Most of these sites render their document lists in JavaScript, so a
plain HTTP fetch returns an empty shell. Discovery needs a browser; downloading
does not, so the two are kept separate.

## `processed/`

| file | contents |
|---|---|
| `pipeline_ranking.csv` | all 48 banks, every factor, score, quadrant and rationale |
| `intent_extractions.json` | classifier output with evidence and source URL per signal |
| `harvest_candidates.json` | the review queue, plus per-bank crawl status |

All three are regenerated by running the pipeline; none are edited by hand.

## Source

EBA EU-wide Transparency Exercise 2025 — bank-level supervisory filings, free and
public. Reporting period **2025-Q2**. Aggregates were checked against published
EBA figures before anything was built on them: weighted NPL ratio 2.41%, Stage 2
share 9.0%.

UK institutions left the EBA sample after Brexit and are therefore not covered.
